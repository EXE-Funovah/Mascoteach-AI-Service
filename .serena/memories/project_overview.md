# Mascoteach AI Service overview
- Purpose: TypeScript/Express microservice for Mascoteach AI capabilities.
- Entry point: `src/app.ts`; dev uses `ts-node-dev`, production build emits `dist/app.js`.
- HTTP areas:
  - `/api/v1/mcq`: legacy multipart upload MCQ generation.
  - `/api/v1/ai`: backend-oriented health check and URL-based quiz generation.
  - `/api/v1/mascot-live`: Agora live orchestration health and session lifecycle.
- WebSocket: `/ws/mascot-live` bridges browser audio/text messages to a Gemini live session and relays audio/events back.
- Layers: `routes/` -> `controllers/` -> `services/`; `middlewares/` handles upload; `config/` handles Agora readiness/config; `types/` contains TypeScript domain types; `websocket/` handles live transport.
- Quiz pipeline: upload or URL download -> optional conversion for Gemini -> Gemini MCQ generation -> normalized JSON response.
- File conversion supports native MIME passthrough and readable extraction/conversion paths for office-like inputs.
- Live stack currently includes direct Gemini WebSocket audio handling plus Agora lifecycle/session orchestration.
- No `README.md`, `docs/ai/context.md`, or `docs/ai/validation.md` existed during onboarding.
